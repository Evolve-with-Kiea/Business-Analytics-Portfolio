# 3. Learning Philosophy

My primary goal is to understand Python well enough to solve new problems independently.

I do not want to rely on copying code without understanding how or why it works.

### My Learning Approach

1. Learn one concept at a time.
2. Read or watch an explanation.
3. Describe the concept in my own words.
4. Review a small example.
5. Create a plain-language plan.
6. Write the code independently.
7. Run the program.
8. Compare actual and expected results.
9. Investigate errors.
10. Modify the program.
11. Explain what changed and why.
12. Document what I learned.

### Important Principle

**Successfully running code is only one part of learning. I also want to understand the logic, explain the process, and apply the concept to a different problem.**

# 11. Variables & Basic Calculations

## Purpose

Learn how to store values and perform calculations.

### Illustrative Example

```python
product_name = "Business Planner"
unit_price = 25
quantity = 4

revenue = unit_price * quantity

print(f"Product: {product_name}")
print(f"Revenue: ${revenue:.2f}")
```

### Expected Output

```text
Product: Business Planner
Revenue: $100.00
```

### Concepts Demonstrated

- Variables
- Strings
- Numbers
- Multiplication
- F-string formatting
- Output

### Learning Questions

- Why are variables useful?
- How is revenue calculated?
- What happens when quantity changes?
- Why is an f-string used?

# 12. Conditional Logic

## Purpose

Understand how programs make decisions.

### Illustrative Example

```python

```

### Expected Output

```text
Discount eligible
```

### Potential Business Applications

- Inventory warnings
- Budget limits
- Payment status classifications

### Important Principle

# 13. Loops & Collections

# 14. Functions & Reusable Code

## Purpose

Learn how to organize calculations into reusable components.

### Illustrative Example

```python
def calculate_profit(revenue, cost):
    return revenue - cost

profit = calculate_profit(500, 300)

print(profit)
```

### Expected Output

```text
200
```

### Learning Questions

- What does `def` mean?
- What are parameters?
- Why is `return` used?
- How can a function be reused?

### Important Principle

Functions help organize code and reduce unnecessary repetition.
