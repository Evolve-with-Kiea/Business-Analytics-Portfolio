# Documentation

This folder contains the standards, sources, methods, and tracking documents that govern every project in the portfolio.

## Contents

| Document | Purpose |
|---|---|
| [Project Documentation Standards](Project-Documentation-Standards.md) | Required elements for every project, a reusable template, and data security rules |
| [Dataset Sources](Dataset-Sources.md) | Reputable sources of public data and how to evaluate them |
| [Analytical Methodology](Analytical-Methodology.md) | A repeatable twelve-step analytical process |
| [Portfolio Progress](Portfolio-Progress.md) | A tracker of planned and completed projects |

## How to Use These Documents

1. Before starting a project, review the methodology and find a suitable dataset.
2. Copy the project template from the standards document.
3. Update the progress tracker when a project changes status.
4. Review the documentation checklist before publishing anything.
