# Portfolio Progress

## Purpose

This tracker lists planned portfolio projects and records their status. It is updated when a project changes status.

## Status Definitions

| Status | Meaning |
|---|---|
| Planned | The project is identified but work has not begun. |
| In Progress | I am actively working on the project. |
| Practicing | I am working through exercises or drafts to build the skills needed. |
| Completed | The project is finished and documented to the standards. |
| Reviewed | A completed project has been checked by me against the standards, and by another person where possible. |
