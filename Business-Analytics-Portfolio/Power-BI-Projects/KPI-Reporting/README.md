# KPI Reporting

## Purpose

This folder is for Power BI reports centered on key performance indicators, targets, and trends.

## KPI Categories

| Category | Example measures |
|---|---|
| Sales performance | Revenue, units sold, average order value, growth |
| Financial performance | Gross margin, operating margin, expense ratio |
| Marketing performance | Conversion rate, cost per acquisition, return on spend |
| Operational KPIs | Cycle time, on-time rate, error rate, inventory turnover |
| Customer metrics | Retention rate, repeat purchase rate, customer lifetime value |


## Reporting Elements

| Element | Purpose |
|---|---|
| Target comparisons | Show actual results against goals |
| Trend reporting | Show direction and seasonality over time |
| Variance indicators | Highlight favorable and unfavorable differences |
| Definitions panel | Explain how each KPI is calculated |


## KPI Documentation Standard

For every KPI, record the definition, formula, data source, target, refresh frequency, and interpretation guidance.
