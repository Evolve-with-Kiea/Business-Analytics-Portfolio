# Power BI Projects

This section will hold Power BI projects that apply data modeling, DAX, and visualization to business reporting. No projects have been completed yet.

## Project Areas

| Folder | Focus |
|---|---|
| [Business-Dashboards](Business-Dashboards/README.md) | End-to-end dashboards from data import to report design |
| [KPI-Reporting](KPI-Reporting/README.md) | KPI-focused reports with targets and trends |

## What This Section Will Demonstrate

- Ability to import, transform, and model data
- Use of DAX for business measures
- Visual design that serves a defined audience
- Documentation of the model and its assumptions

Power BI files (.pbix) can embed data. Before publishing one, confirm that all data is public, synthetic, or anonymized and that the dataset license permits redistribution.

## How Projects Are Added

1. Choose a business question and note it in the project README.
2. Select a public, synthetic, or anonymized dataset (see [Dataset Sources](../Documentation/Dataset-Sources.md)).
3. Follow the [Analytical Methodology](../Documentation/Analytical-Methodology.md).
4. Document the project using the [Project Documentation Standards](../Documentation/Project-Documentation-Standards.md).
5. Update [Portfolio Progress](../Documentation/Portfolio-Progress.md).
