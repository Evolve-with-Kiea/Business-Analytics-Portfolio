# Business Dashboards

## Purpose

This folder is for Power BI dashboards that move from raw data to a finished report for a defined audience.

## Project Stages

| Stage | What to document |
|---|---|
| Data importing | Source, connection method, and refresh considerations |
| Data transformation | Cleaning steps in Power Query and the reason for each |
| Data modeling | Table structure, such as fact and dimension tables |
| Relationships | Keys, cardinality, and filter direction |
| DAX fundamentals | Measures created, their definitions, and how they were validated |
| Visualizations | Why each visual type was selected |
| Dashboard design | Layout, hierarchy, color, and readability |
| Filters and slicers | How users explore the data |
| Business reporting | Who reads the report and what decisions it supports |


## Design Checklist

- [ ] Audience and purpose stated
- [ ] Most important KPIs placed prominently
- [ ] Visuals match the questions being asked
- [ ] Consistent colors, labels, and number formats
- [ ] Slicers tested for correct filtering
- [ ] Measures verified against known values
- [ ] Accessibility considered, such as contrast and not relying on color alone

## Documentation Notes

Include a data model diagram and a table of measures with definitions. Screenshots of the final report help reviewers who cannot open the file.
