# Case Study Data Analysis

## Purpose

This folder is for the analytical stage of a case study: documenting the dataset, preparation, methods, and findings.

## Template

```markdown
## Dataset
- Source and link:
- License and permitted use:
- Time period and size:
- Description of key fields:
- Reliability and privacy considerations:

## Data Preparation
- Issues found (missing values, duplicates, inconsistencies):
- Cleaning steps and the reason for each:
- Records before and after cleaning:

## Analytical Methods
- Methods chosen and why they fit the questions:
- Tools used:

## Findings
- Finding 1, with supporting evidence or visualization:
- Finding 2:
```

## Guidance

- Link each finding to a research question.
- Show enough detail for another person to reproduce the steps.
- Report results that contradict expectations.
- Keep description separate from interpretation until the recommendations stage.
