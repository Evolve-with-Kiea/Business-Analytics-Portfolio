# SQL Projects

This section will hold SQL projects that show how databases and queries answer practical business questions. No projects have been completed yet.

## Project Areas

| Folder | Focus |
|---|---|
| [Database-Analysis](Database-Analysis/README.md) | Understanding database structure and retrieving data |
| [Business-Queries](Business-Queries/README.md) | Queries that answer specific business questions |

## What This Section Will Demonstrate

- Understanding of how relational data is organized
- Ability to write and explain queries
- Translation of business questions into SQL
- Validation of query results

## How Projects Are Added

1. Choose a business question and note it in the project README.
2. Select a public, synthetic, or anonymized dataset (see [Dataset Sources](../Documentation/Dataset-Sources.md)).
3. Follow the [Analytical Methodology](../Documentation/Analytical-Methodology.md).
4. Document the project using the [Project Documentation Standards](../Documentation/Project-Documentation-Standards.md).
5. Update [Portfolio Progress](../Documentation/Portfolio-Progress.md).
