# Beginner Projects

## Purpose

This folder is for small Python programs that practice fundamental concepts while connecting them to simple business situations. The goal is to understand why code works, not to copy solutions.

## Concepts and Possible Business Uses

| Concept | Simple business application |
|---|---|
| Variables and data types | Store a product price, quantity, and name |
| Strings | Format a receipt line or clean a product name |
| Numbers | Calculate totals, discounts, and margins |
| Conditional statements | Apply a discount only above a purchase threshold |
| Loops | Process a list of orders |
| Functions | Create a reusable profit margin calculator |
| Lists | Store a series of monthly sales values |
| Dictionaries | Map product names to prices |
| Basic calculations | Compute revenue, cost, and profit |


## Learning Approach

- Study the concept, then write an explanation in my own words.
- Write the program from a plain-language plan before coding.
- Modify an example and describe what changed and why.
- Test with several inputs, including unusual ones.
- Record what was confusing and how I resolved it.

## Project README Should Include

- The concept being practiced
- The business scenario
- How the program works, step by step
- Example inputs and the output I observed when I ran it
- What I would improve
- What I learned
