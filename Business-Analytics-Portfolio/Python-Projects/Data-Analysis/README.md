# Python Data Analysis

## Purpose

This folder is for future Python data analysis projects. These templates describe the workflow I intend to follow after building programming fundamentals. I have not completed these projects.

## Project Workflow

| Stage | What it involves |
|---|---|
| Data loading | Reading a public or synthetic dataset into Python |
| Data cleaning | Handling missing values, duplicates, and inconsistent formats |
| Data organization | Structuring data for analysis |
| Exploratory data analysis | Examining distributions, categories, and relationships |
| Statistical summaries | Counts, averages, medians, and spread |
| Trend identification | Looking for patterns over time |
| Data visualization | Charts that communicate findings |
| Business recommendations | Actions supported by the analysis |


## Prerequisites Before Starting

- [ ] Comfortable with variables, loops, functions, lists, and dictionaries
- [ ] Understand the dataset's meaning and source
- [ ] Know what business question the analysis answers
- [ ] Learn the basics of a data library such as pandas through its [official documentation](https://pandas.pydata.org/docs/)
