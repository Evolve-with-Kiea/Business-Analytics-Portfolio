## How to Organize Platform Projects

This folder is a **platform discovery index**. A platform is a source system or analysis environment, not necessarily a separate project. Link to one canonical case study after a real platform export or integration is used; do not claim hands-on platform analytics from a proposed idea.

**Recommended classification:** Standalone for a new platform business problem; Extension when a new platform integration enhances existing work; Integrated case study when multiple systems support one decision. [Portfolio Organization Guide](../Documentation/Portfolio-Organization.md).
