## How to Organize Industry Projects

This folder is an **industry discovery index**, not a second copy of technical projects. When a case study is developed, select one primary project folder and add links here by industry. A retail sales dashboard built in Excel should not be copied here solely because it concerns retail.

**Recommended classification:** Standalone for an independent industry problem; Extension for a new industry-specific method applied to an existing analysis; Integrated case study for multi-function solutions. [Portfolio Organization Guide](../Documentation/Portfolio-Organization.md).
