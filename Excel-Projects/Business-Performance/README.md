# Business Performance

## Purpose

This folder is for Excel projects that track business performance against goals using KPIs.

## Focus Areas

| Area | Content |
|---|---|
| KPI tracking | Defining KPIs and monitoring them over time |
| Performance measurement | Comparing results with targets and benchmarks |
| Revenue trends | Period-over-period changes |
| Productivity | Output relative to input, such as orders per employee |
| Operational performance | Cycle time, error rate, and fulfillment measures |
| Business goal tracking | Progress toward stated objectives |


## KPI Definition Standard

For each KPI, document: name, definition, formula, data source, update frequency, target, and how to interpret it. A KPI without a definition cannot be reliably compared over time.

## Suggested Excel Techniques

- Scorecard layouts with target and actual columns
- Conditional formatting for status indicators
- PivotTables and charts for trends
- Named ranges and a labeled assumptions sheet
