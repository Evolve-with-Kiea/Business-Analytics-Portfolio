## Publication Review Checklist

- [ ] Business problem and objectives are clearly documented.
- [ ] Dataset source, permissions, and privacy requirements are verified.
- [ ] Data dictionary and reporting period are documented.
- [ ] Cleaning and transformation steps are reproducible.
- [ ] KPI formulas and assumptions are documented.
- [ ] Calculations have been independently validated.
- [ ] Financial totals reconcile where applicable.
- [ ] Dashboards and reports display accurate results.
- [ ] Screenshots contain no confidential information.
- [ ] Findings are supported by analytical evidence.
- [ ] Recommendations are clearly distinguished from verified outcomes.
- [ ] All deliverable files and links have been tested.
- [ ] Guided work and independent contributions are accurately described.
- [ ] Project status reflects the work actually completed.

## Project Status Definitions

| Status | Meaning |
|---|---|
| **Planned** | Project identified; analytical work has not begun |
| **In Progress** | Data preparation, analysis, or development is underway |
| **Draft for Review** | Initial deliverables exist but require validation or review |
| **Verified** | Analytical outputs and calculations have been checked |
| **Portfolio-Ready** | Verified project is documented, reviewed, and suitable for presentation |
