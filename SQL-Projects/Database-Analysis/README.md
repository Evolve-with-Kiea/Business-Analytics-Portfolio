# Database Analysis

## Purpose

This folder is for projects that explore a relational database: how it is structured, how tables relate, and how to retrieve data from it.

## Concepts to Document

| Concept | What to explain |
|---|---|
| Database structure | The purpose of the database and the business process it represents |
| Tables | What each table stores and what one row represents |
| Primary keys | The column that uniquely identifies each row |
| Foreign keys | How a column in one table references another |
| Relationships | One-to-many and many-to-many connections, shown in a diagram |
| Database exploration | Reviewing tables, columns, data types, and row counts |
| Data retrieval | Queries used to examine the data |


## Exploration Checklist

- [ ] List all tables and describe each
- [ ] Identify keys and relationships
- [ ] Check for missing values and duplicates
- [ ] Confirm data types make sense
- [ ] Draw an entity relationship diagram
- [ ] Record questions the data can and cannot answer

## Why This Matters

A query is only as reliable as the analyst's understanding of the data. Misreading how tables relate is a common source of wrong results, particularly with joins.
