# Customer Analysis

## Purpose

This folder is for projects that examine who customers are, how they behave, and how long they stay.

## Topics

| Topic | What to analyze |
|---|---|
| Customer acquisition | How many new customers arrive and at what cost |
| Customer retention | How many customers continue to buy |
| Customer lifetime value | Expected value of a customer over time |
| Repeat purchases | How often customers return |
| Customer segmentation | Grouping customers by behavior or characteristics |
| Purchasing behavior | What, when, and how customers buy |


## Segmentation Approaches

- Recency, frequency, and monetary value
- Product or category preference
- Order value bands
- Acquisition channel

## Privacy Requirement

Use only synthetic or properly anonymized customer data. Never publish names, emails, addresses, payment details, or any information that could identify an individual.
